# Panel de stock (Google Apps Script)

App web privada para cargar autos y editar precio / vendido / destacado desde el celular.
Está instalada como script vinculado a la planilla **ADG Autos - Stock** (Extensiones → Apps Script).
Esta carpeta es solo una copia de respaldo del código: la web no la usa.

- `Codigo.gs`: lógica (planilla + Drive)
- `Panel.html`: pantalla

Para actualizarlo: pegar los archivos en el editor de Apps Script y en Implementar → Gestionar implementaciones → editar → Nueva versión.
